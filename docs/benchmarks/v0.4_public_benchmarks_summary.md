# v0.4 Public Benchmarks Summary

Public/sub-public adapters run end-to-end through the local deterministic subset harness:

- LongMemEval-S subset adapter
- LoCoMo QA subset adapter
- MemoryAgentBench mini adapter
- RULER-style synthetic adapter
- LoCoMo real mini subset: 30 QA pairs converted from `snap-research/locomo` `data/locomo10.json`

Current limitation:

- LongMemEval-S and MemoryAgentBench adapters currently reuse the deterministic local subset shape.
- Exact source spans are marked as approximated when unavailable.
- No public metric is fabricated.

Result:

- `full_compiler` matches `compressed_core_plus_recall` in this scaffold.
- On LoCoMo real mini, `full_compiler` reaches accuracy `1.0`, source_recall@5 `1.0`, and fewer total tokens than `naive_rag` in the local deterministic harness.
- Public benchmark ingestion is runnable, but full external benchmark validation remains future work.
